# 健康監測系統（醫療訊號處理實作期末報告）

大三下「醫療訊號處理實作」期末報告。兩塊 Arduino 收集生理訊號與環境數值，連接視窗程式即時顯示並存進資料庫。

## 主要功能

- 生理數值：心電圖（ECG）、心率、血氧、體溫，並偵測心電電極是否脫落
- 環境數值：溫度、濕度、距離、人體感應
- 即時顯示心電圖波形與各項數值，兩塊板的資訊以分頁分開
- 心率、血氧、體溫連同姓名、學號存入 SQLite 資料庫
- 數值異常以紅色標示
- 管理者登入後可查看過往紀錄

## 使用技術

- C#、Windows Forms、SQLite
- Arduino 感測器：心電模組、MAX30102（血氧）、AM2320（溫濕度）、MLX90614（非接觸體溫）、VL53L0X（距離）、PIR（人體感應）
- 傳輸：心電波形資料量大走 USB；環境與體溫每秒一筆，走藍牙
- 心率：在Arduino上從心電波形抓出每次心跳換算成每分鐘次數，略過不合理的數值並取最近幾次平均
- 血氧：依紅光與紅外光讀值的比例估算

## 程式架構

```
medical-signal-report/
├── arduino/
│   ├── sketch_jun14a/          環境板：讀取溫濕度、體溫、距離、人體感應，使用藍牙傳送
│   └── sketch_jun14b/          生理板：讀取心電圖與血氧並算出心率，用 USB 傳送
├── 醫療訊號期末報告/
│   ├── InterForm.cs            開始畫面
│   ├── MainForm.cs             主畫面：接收資料、顯示數值與波形
│   └── SQLiteService.cs        資料庫存取
└── 醫資實驗期末報告後台測試/    測試藍牙接收資料的小程式
```

1. 兩塊Arduino讀取感測器數值，分別用USB和藍牙傳到電腦
2. C#程式透過序列埠接收資料，依每行開頭的標記辨識資料種類並即時顯示
3. 量測結果存進SQLite資料庫

## 執行方式

把 `arduino/sketch_jun14a` 燒錄到環境板、`arduino/sketch_jun14b` 燒錄到生理板，再用 Visual Studio 開啟 .sln 執行。生理板以 USB 連接，環境板以藍牙連接（藍牙在程式中手動開關）。
